# Materiały do rolki Studio Sygnatura

Wrzucaj tutaj oryginalne zdjęcia i krótkie nagrania przeznaczone do montażu. Przykładowa nazwa klipu: `laser-grawer.mp4`.

- Najlepiej pionowo 9:16, 1080p, bez muzyki i filtrów.
- Pojedynczy klip z grawerowania może mieć 3–8 sekund; dobrze, jeśli widać zbliżenie detalu i moment pracy lasera.
- Nie pokazuj danych klienta ani prywatnych zamówień bez zgody.
- To repozytorium jest publiczne — każdy plik dodany i zatwierdzony w GitHub będzie publicznie dostępny. Nie umieszczaj tu niczego, czego nie chcesz upublicznić.
- Folder jest poza `docs/`, więc materiały nie są publikowane jako pliki strony Studio Sygnatura.
