# Szopka 20×20 — plan warstw (propozycja 29.08.2026)

Patrzysz **od frontu**. Numeracja L1 → tył. L6–L7 to nie obraz, tylko skrzynka na baterie.

Pliki: `L1`…`L7` PNG/SVG w tym folderze. Sylwetki zwierząt = **makieta proporcji**, nie plik cięcia. Cięcie zwierząt — Inkscape u Ciebie (jak w `CIECIE/CZYTAJ-TO-NAJPIERW.md`).

## Werdykt na Twoją kolejność

**Kolejność narracji jest dobra.** Owce i plotek z przodu, Święta Rodzina jako jeden kadr, zwierzęta *w* stajni, dach góruje, niebo na końcu — to czytelny tunel, nie płaski teatr cieni.

**Trzy korekty, zanim narysujesz na poważnie:**

1. **Anioł nie na L3 ze zwierzętami.** Na L3 zostaje wół / osioł (ew. pasterz nisko z boku). Anioł — mały, na kalenicy L4 albo jedna gwiazda-anioł w L5. Inaczej anioł stoi w oborze.
2. **Chmurki na L2 tylko w prześwitach dachu**, nie przez środek. L4 musi zostawić dwa „okna” nieba po bokach kalenicy — tam wychodzą chmury L2. Imitacja głębi nieba działa tylko, gdy dach ich nie zasłania.
3. **Nie 7 warstw obrazu.** L6 przegroda + L7 plecki to mechanika. Obraz: **5 płaszczyzn**. Grzebień: 5 wpustów sceny + 1 wpust przegrody. Głębokość skrzynki wyjdzie **~55–65 mm**, nie 40 mm z dokumentacji 5-warstwowej — listwa 20×20 mm już nie obuduje całości; korpus wyższy (ścianki ~55–60 mm).

**Koszyk w dnie ostatnich warstw — tak, ale tylko L6+L7.** Nie wybieraj dna L1–L5 (osłabiłoby pierwsze plany i widać by było szczelinę). Szufladka 2×AA / 3×AA wsuwana od spodu lub od tyłu, włącznik w licu dolnej ścianki.

L5 = same otwory (gwiazda + dziurki). Światło łapie **białe matowe L7**. Bez tego gwiazdy są czarnymi dziurami.

## Warstwa po warstwie

| | Co widać | Po co | Góra otwarta? |
|---|---|---|---|
| **L1** front | 2–3 owce + plotek / zagroda; pas ziemi; **od góry powietrze** | pierwszy plan, „jesteś na polu”; nie zasłania żłóbka | tak, max ~40% wysokości |
| **L2** | Maryja + Józef + żłóbek **w jednym kadrze**; dwie chmury tylko po bokach | serce sceny; chmury bliżej niż niebo | środek otwarty nad głowami |
| **L3** | Wół + osioł (ew. pasterz nisko). Bez anioła | wypełnia łuk stajni za rodziną | tak nad grzbietami |
| **L4** | Stajnia: dach dwuspadowy **góruje**, szeroki łuk, okna; **zostawia niebo** na L5 | rama architektury, nie zasłona gwiazd | wycięty łuk + niebo nad okapem |
| **L5** | Gwiazda Betlejemska + mniejsze + „pył” otworów | świecące niebo | prawie cała płyta, dziury |
| **L6** | Pełna płyta, małe otwory na drut, wycięcie koszyka **dołem** | przegroda: z przodu scena, z tyłu brud (baterie, supeł drutu) | nie |
| **L7** | Plecki, **biały mat do wewnątrz**, klapka / szuflada baterii | odbłyśnik + serwis | zdejmowane |

Stare pliki `CIECIE/`: L0≈nowe L5, L1≈L4, L3+żłóbek z L4≈nowe L2. L2 wzgórza — w tym układzie **odpada** (zastępuje je plotek L1 + zwierzęta L3).

## Bejca / farba (od frontu)

Cel: **cieplej i jaśniej do środka**, tył ciemniejszy żeby gwiazdy czytały się jako światło, nie jako dziury w jasnej sklejce.

| Warstwa | Propozycja A (rekomendowana) | Propozycja B (surowsza) |
|---|---|---|
| L1 plotek, ziemia | surowa brzoza / olej bez bejcy | jasny dąb |
| L1 owce | **farba** kredowa złamana biel, nie bejca | to samo |
| L2 rodzina | orzech średni `#6B4530` (znak Sygnatury) | palisander jasny |
| L2 chmury | biel kredowa, bardzo mat | ecru |
| L3 zwierzęta | orzech ciemniejszy o 1 ton | wenge jasne |
| L4 stajnia | miód / teak — cieplejsza od figur, żeby dach „palił się” w LED 2700 K | surowa + olej |
| L5 niebo | **grafit / heban** od frontu (płyta znika, świecą tylko otwory) | granat farba, nie bejca |
| L6 | cokolwiek; od frontu nie widać | — |
| L7 wewnątrz | **biel mat** (kredowa) — obowiązek | to samo |
| Ścianki wewnątrz | biel mat | biel mat |
| Rama / listwa | orzech `#6B4530` jak znak | czarny olej |

Nie maluj krawędzi cięcia na L5 (zostaw spaleniznę lasera albo lekki olej) — czarna dziura + ciepła krawędź wygląda jak niebo.

Owce: farba, nie bejca — bejca na wełnie wygląda jak mokre drewno, nie jak zwierzę.

## Głębokość (żeby nie zdziwić przy ramie)

5×3 mm sceny + 1×3 mm L6 + 5 szczelin × 6 mm ≈ **48 mm** do L7 + kieszeń baterii **12–16 mm** za L6 → **korpus ~60 mm**.  
Grzebień: szczeliny 3,2 mm, test na odpadzie. Kerf bez kompensacji jak dotychczas.
