# Studio Sygnatura — strona

Statyczna strona (czysty HTML, zero zależności). Każdy plik zawiera style,
logo i skrypty wbudowane w środku, więc działa też po otwarciu z dysku.

## Podgląd na żywo
GitHub Pages: **Settings → Pages → Source: Deploy from a branch → main / (root)**

## Pliki
| Plik | Zawartość |
|---|---|
| `index.html` | Start |
| `rzemioslo.html` | O nas — dwie sylwetki |
| `metryczki.html` | Metryczka podświetlana |
| `numery.html` | Numery na drzwi |
| `szyldy.html` | Szyldy rzeźbione |
| `wynajem.html` | Wynajem + terminarz + rezerwacja |
| `wspolpraca.html` | Dla organizatorów uroczystości |
| `dla-firm.html` | Hotele, pensjonaty, firmy |
| `kontakt.html` | Formularz kontaktowy |
| `404.html` | Kopia strony startowej |
| `.nojekyll` | Wyłącza przetwarzanie Jekyllem |

## Uwaga
Wersja poglądowa: zdjęcia to placeholdery, formularze nic jeszcze nie wysyłają,
a terminarz pokazuje dane przykładowe. Źródła (`pages.py`, `build.py`,
`assets/`) leżą w katalogu `www/site` w materiałach roboczych.
